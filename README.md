# Telegram Bot API Client: Authors & Books

Telegram-бот на Python, который работает как клиент для REST API (ASP.NET) с авторами и их книгами. Через чат можно получать, создавать, изменять и удалять авторов, то есть выполнять полный набор CRUD-операций без Swagger и Postman.

## Возможности

| Команда | Описание | HTTP-метод |
|---|---|---|
| `/authors <id>` | Информация об авторе и список его книг | `GET /authors/{id}` |
| `/authorslist` | Список всех авторов с книгами | `GET /authors` |
| `/createauthor` | Пошаговое создание автора с книгами (до 10 книг) | `POST /authors` |
| `/edit` | Пошаговое изменение имени и возраста автора | `PUT /authors/{id}` |
| `/delete` | Удаление автора по ID | `DELETE /authors/{id}` |

## Что реализовано

- **Пошаговые диалоги** через `register_next_step_handler`: бот собирает данные по одному полю и хранит состояние каждого чата отдельно по `chat_id`.
- **Валидация ввода** на стороне бота: ID и возраст только числами, возраст в диапазоне 1-119, длина имени и названия до 150 символов, год книги не позже текущего.
- **Разбор ошибок API**: для ответов `400` бот показывает ошибки валидации сервера в формате ASP.NET (`errors`, `detail`, `title`).
- **Обработка сетевых сбоев**: таймауты запросов, понятные сообщения при недоступном сервере, статусы `404` и `5xx`.
- **Экранирование HTML** (`html.escape`) в `/authorslist`, чтобы пользовательские данные не ломали разметку сообщения.
- **Секреты в `.env`**: токен бота не хранится в коде.

## Стек

- Python 3

## Требования к бэкенду

Бот ожидает, что REST API с эндпоинтом `/authors` запущен локально по адресу `https://localhost:7003`. Сам бэкенд в этот репозиторий не входит.

Ожидаемый формат автора:

```json
{
  "id": 1,
  "name": "Имя автора",
  "age": 45,
  "books": [
    { "title": "Название книги", "publishedYear": 2001 }
  ]
}
```

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/swmqq/telegram-bot-api.git
   cd telegram-bot-api
   ```

2. Установите зависимости:

   ```bash
   pip install pyTelegramBotAPI requests python-dotenv
   ```

3. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.

4. Создайте файл `.env` в корне проекта:

   ```
   BOT_API=your-telegram-bot-token
   ```

5. Запустите бэкенд, затем бота:

   ```bash
   python bot.py
   ```

## Известные ограничения

- Запросы выполняются с `verify=False`, потому что локальный сервер использует самоподписанный сертификат. Это допустимо только для локальной разработки.
- Состояние диалогов хранится в памяти процесса и пропадает при перезапуске бота.
- `/authorslist` выводит всех авторов одним сообщением, пагинации пока нет.
- `/edit` меняет только имя и возраст автора, книги не редактируются.

## Планы

- Пагинация в `/authorslist`
- Редактирование и удаление отдельных книг
- Вынос адреса API в `.env`
- Запуск в Docker вместе с бэкендом
